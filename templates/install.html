Add Auto Poster AI to your device.

Install the web app from a supported browser, or keep using the website. The app and your account use the same hosted service.

Install the web app

Use your device’s instructions below. A browser install button appears here when supported.

Cloud publishing and private workspace screens need an Internet connection. This installation does not download your private account pages or post drafts for offline use.

iPhone and iPad

  1. Open this app’s website in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen, then tap Add.

If this page opened inside another app, open its link in Safari first.

Android

  1. Open this app’s website in Chrome.
  2. Tap Install Auto Poster AI above when it appears, or open Chrome’s menu.
  3. Choose Install app or Add to Home screen and follow the prompt.

Windows and macOS

In Chrome or Edge, use the install icon beside the website address or the browser menu’s Install app command. Availability depends on the browser and service configuration.
