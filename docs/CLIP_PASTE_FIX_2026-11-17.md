# Clip Studio paste and highlight fix — November 17, 2026

The URL box was hidden or disabled by renderer/import readiness and the default
upload selection. It is now permanently visible, focusable and editable. Link
checking reports supported format and service readiness without a download,
job or render allowance. Processing retains authentication, verification and
provider safety gates. Inactive source data is removed from the submitted form.

Real clipboard paste passed in Chromium at phone and desktop sizes, including
an unverified account with rendering and network importing unavailable. Switching
sources preserves the pasted URL. Link checks do not expose signed query strings.

Highlight selection now prefers complete sentence/pause boundaries and useful
openings/payoffs, penalizes repetition/promotions/long silence, and respects the
requested duration. Five new selection tests and fourteen existing adapter tests
passed. This is transcript-based ranking, not measured engagement or a claim to
be the best editor in the market. Live Render/media provider access remains
unverified, and this change does not enable unsupported or protected sources.
